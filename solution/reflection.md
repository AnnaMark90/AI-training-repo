# Рефлексия

что агент сделал хорошо: перед написанием теста снял реальный DOM карточки со стенда (кнопка, цена, опции, галерея) и не придумал ни одного нового селектора. Все пробелы Page Object (выбранная опция, группы опций, галерея, префикс `From`) назвал явно. В негативный тест сам добавил контрольный шаг против false positive. Каждый тест проверил мутацией: испортил данные, убедился, что тест падает.
где ошибся: сразу сделал негативный тест data-driven на два случая (N1, N2), хотя заданию хватало одного; пришлось сокращать. Префикс `From` у цены заметил только после присланного HTML, хотя мог увидеть его ещё на этапе Research, если бы снимал разметку вместе с обёрткой цены. Просьба прислать HTML галереи оказалась недостаточно конкретной: вместо карточки товара пришёл HTML каталога.
что изменить в промпте в следующий раз (хотя бы одна конкретная правка промпта): добавить в промпт Research «для каждого локатора Page Object, участвующего в кейсе, сними outerHTML его родителя в состояниях до и после действия». Тогда разница вида `From €10.00` → `€10.00` нашлась бы сразу. И сразу указывать объём: «один позитивный тест и один негативный случай, без data-driven».
