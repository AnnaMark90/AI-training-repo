# План автоматизации

**Кейс:** TC-03 — Выбор варианта (BF-02 Выбор варианта и корзина, P0). Связанные проверки регрессии: RC-13, RC-14 (автоматизированы), RC-11 (не автоматизирована, см. ниже).

## Контекст (Research)

- Страница(ы): карточка товара Medusa T-Shirt `/dk/products/t-shirt`, регион Denmark, валюта EUR. Роль: гость (`SESSION_STORAGE_STATE`).
- Page Object: существующий `pages/store/product.page.ts` (`ProductPage`), дополнен локатором `priceLabel` (цена вместе с префиксом `From`). В `fixtures/index.ts` добавлена фикстура `productPage`.
- Эталонный тест для стиля: `tests/store/catalog.spec.ts`.
- Реальная разметка снята со стенда (до выбора, после Black, после Black + M) и сверена с присланным HTML блока опций:
  - `add-product-button`: до выбора и при одном Black — `disabled`, текст `Select variant`; после Black + M — активна, текст `Add to cart`;
  - `product-price` (`€10.00`) лежит в `<span>` без `data-testid`: до полного выбора текст обёртки `From €10.00`, после — `€10.00`;
  - опции: две группы `product-options` (Select Color: Black, White; Select Size: S, M, L, XL), у обёрток групп нет `data-testid`; выбранная кнопка отличается только CSS-классом;
  - галерея: 4 статичных `img` (`Product image 1–4`), не кликабельны, переключения нет;
  - URL после выбора варианта не меняется (`?v_id` не пишется).
- Тестовые данные, валидные: handle `t-shirt`, заголовок `Medusa T-Shirt`, вариант Color `Black` + Size `M`, цена `€10.00`.
- Тестовые данные, невалидные: неполный вариант — выбран только Color `Black` без Size.

## Шаги и проверки

### Позитивный: `TC-03: Add to cart is enabled only after Black / M is selected, price is €10`

| #   | Шаг                           | Проверка                                                           | UI / API | Почему так                                                                                                             |
| --- | ----------------------------- | ------------------------------------------------------------------ | -------- | ---------------------------------------------------------------------------------------------------------------------- |
| 1   | `productPage.goto('t-shirt')` | `title` = `Medusa T-Shirt`                                         | UI       | Открыта нужная карточка, а не 404 или другой товар                                                                     |
| 2   | Ничего не выбирать (RC-13)    | `addToCartButton` `toBeDisabled()`, `toHaveText('Select variant')` | UI       | Текст отличает «вариант не выбран» от «Out of stock»: в обоих случаях кнопка выключена                                 |
| 3   | Там же                        | `priceLabel` = `From €10.00`                                       | UI       | Фиксирует исходное состояние «цена от»: опора для проверки в шаге 6                                                    |
| 4   | `selectVariant('Black', 'M')` | —                                                                  | UI       | Действие из Page Object, точное совпадение текста (`L` не цепляет `XL`)                                                |
| 5   | Проверить кнопку (RC-14)      | `addToCartButton` `toBeEnabled()`, `toHaveText('Add to cart')`     | UI       | Вариант определён, его можно добавить                                                                                  |
| 6   | Проверить цену (RC-14)        | `priceLabel` = `€10.00` (префикса `From` нет)                      | UI       | Все 8 вариантов стоят €10: сумма видна и без выбора. Только исчезновение `From` доказывает, что показана цена варианта |

### Негативный: `TC-03-NEG: Add to cart stays disabled when only Color Black is selected`

| #   | Шаг                                   | Проверка                                                           | UI / API | Почему так                                                                                                                        |
| --- | ------------------------------------- | ------------------------------------------------------------------ | -------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 1   | `productPage.goto('t-shirt')`         | `title` = `Medusa T-Shirt`                                         | UI       | Та же страница                                                                                                                    |
| 2   | `selectVariant('Black')`              | `addToCartButton` `toBeDisabled()`, `toHaveText('Select variant')` | UI       | Одного Color недостаточно, чтобы определить вариант                                                                               |
| 3   | Там же                                | `priceLabel` = `From €10.00`                                       | UI       | Цена не переключилась на вариант при неполном выборе                                                                              |
| 4   | Контрольный шаг: `selectVariant('M')` | `addToCartButton` `toBeEnabled()`                                  | UI       | Кнопка выключена ещё до клика, поэтому шаг 2 прошёл бы и при потерянном клике. Включение после M доказывает, что Black применился |

## Ограничения и запросы к разработке

- **`priceLabel` без `data-testid`.** Обёртка цены `From …` не имеет test-id, поэтому локатор — `span`, содержащий `product-price`: без индексов и XPath, но это отступление от правила README «data-testid locators». Запрос к разработке: добавить `data-testid` на обёртку цены. После этого перевести `priceLabel` на `getByTestId`.
- **Выбранная опция.** Есть только CSS-класс; нужен `aria-pressed` или `data-selected` на `option-button` (нужно для случаев 3 и 5).
- **Группы опций.** У обёрток групп нет `data-testid`; для TC-03 не мешает, значения Color и Size не пересекаются.
