# Definition of Done

- Диагноз причины падения подтверждён реальным повторным запуском пайплайна, а не только объяснением Claude.
- Все 4 артефакта из Шага 3 подготовлены и приложены.
- В рефлексии явно указано минимум одно место, где потребовалось скорректировать вывод Claude.
- Использован хотя бы один шаблон промпта из обучающего материала, адаптированный под реальные данные песочницы.
