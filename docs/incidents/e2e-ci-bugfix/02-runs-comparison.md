## Значимые различия

1. **Наличие секретов. Это главное различие.**
   - В успешном запуске `SESSION_URL`, `ADMIN_EMAIL` и `ADMIN_PASSWORD` пустые (лог, строки 243–246). Сработал шаг `Skip e2e without a stand`, строка 369: `Secret SESSION_URL is not set, e2e tests skipped`. Шаги 6–10 (кэш, браузеры, тесты, артефакт, `Test summary`) **не выполнялись**.
   - В упавшем запуске секреты заданы (в логе замаскированы как `***`). Все шаги выполнились, включая сломанный `Test summary`.
   - Секреты созданы в 09:49:47–09:50:14, между двумя запусками.
2. **Код одинаковый.** Оба запуска собраны из `063c6a5`, и дефектный скрипт был в обоих. Зелёный статус первого запуска **ложный**: проблемный шаг просто не дошёл до выполнения. Изменения в коде к падению не привели.
3. **Тесты.** В успешном запуске не запускались. В упавшем: `7 passed (30.3s)`.
4. **Событие и режим.** Ручной запуск с `run-mode=full` выполнил `npm run test`. При `push` этот input пустой, и тоже выбирается `test`. На падение не влияет.
5. **Кэш браузеров.** В успешном запуске шаг пропущен. В упавшем: `Cache not found` (строка 187), а после падения кэш не сохранён (`Post Cache Playwright browsers: skipped`).
