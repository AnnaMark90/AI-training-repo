# Отчёт: микро-делегирование

## Список зафиксированных микро-задач

1. написание скилла для форматирования текста в формат `.md` — делегировать сразу
2. составление текста для сообщения — делегировать сразу
3. скилл объяснение части кода/файла — делегировать пакетом
4. мелкая техническая задача по написанию скриптов для запуска — делегировать сразу

## Короткая рефлексия

### Что агент сделал хорошо

- успешно настраивает скиллы: задает релевантные вопросы и формирует скилл, который отрабатывает ожидаемо
- выполняет задачу согласно промту, при конкретном описании
- логично формулирует сообщения

### Где ошибся

- дает слишком развернутый ответ и лишнюю информацию либо дает слишком кратко, учитывая просьбу о кратком и четком ответе

### Что изменить в промпте в следующий раз (хотя бы одна конкретная правка промпта)

- явно указывать о количестве предложений при написании сообщений. также указывать формат и стиль общения, суть предложения
- создавать план ответа при создании скиллов

### Хватило бы для задач более лёгкой/быстрой модели вместо самой мощной

для мелких технических задач подошел бы вариант с легкой моделью, для остальных нет, так как необходимо обрабатывать больше информации и работать с ней, не теряя контекст.
